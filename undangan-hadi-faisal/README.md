# Undangan Pernikahan Hadi & Faisal

Website undangan statis untuk GitHub Pages.

## Isi
- `index.html` — halaman utama
- `style.css` — desain responsive
- `script.js` — countdown, RSVP demo, dan backsound ambient
- `assets/` — tempat foto/asset tambahan

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file di folder ini ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan, lalu tunggu proses deployment.

## Yang perlu diganti sebelum dibagikan
- Placeholder huruf H/F dengan foto asli.
- Link Google Maps dengan pin rumah yang tepat.
- Isi love story.
- RSVP demo bisa dihubungkan ke Google Sheets/Form atau backend jika ingin benar-benar menyimpan data.

### Catatan musik
Website menggunakan melodi ambient sederhana yang dibuat oleh Web Audio API, sehingga tidak membutuhkan file lagu berhak cipta. Kalau ingin lagu pernikahan tertentu, tambahkan file audio yang kamu punya izin untuk digunakan.
